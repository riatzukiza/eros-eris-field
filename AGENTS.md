## Semantic boundary

- Prefer portable pure `.cljc` law, shape and domain code. CLJS/Node, TypeScript,
  provider HTTP, persistence and visualization belong in outward adapters.
- Keep one physical computation authority. A TypeScript compatibility facade
  must delegate to its qualified compiled artifact, not duplicate force logic.
- Canonical Katamorph shapes, Axxium authorization and Clio event semantics
  retain their authority. Consume them; do not create competing implementations.
- The pure transition cannot read clocks, call models, fetch providers, use
  `Math.random`, publish, or write storage. Host elapsed time and validated
  inputs enter as data. Refusals preserve prior state.
- Memory visibility applies before every causal influence, including retained
  fields and trails. Display filtering is not authorization.
